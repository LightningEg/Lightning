## Report
Owner, 2026-10-31: tracking lives in three places (the decision dashboard `analytics/dashboard.html`, the store and community views in `admin.html`, and GoatCounter's own site). Marketing needs one place with several analyses.

## Fix
Move every view into the owner console (`admin.html`, generated by `tools/store_admin.py`) as tabs, keeping the key-gated, nothing-committed rules in README › Analytics and consent. The old dashboard page redirects, then goes. Each tab answers one question and says when its data is stale or too thin to read.

## 8X1 Inventory
List every figure on the dashboard, the owner console and the daily GoatCounter job; mark the duplicates and the ones nobody acts on.

## 8X2 Tabs
Visitors and sources, Downloads funnel, Search and findability, Store and coins, Errors and speed, with the 11 decision rules from `analytics/rules.js` leading.

## 8X3 Move and redirect
Port the data reads, keep the tests (`rules.test.js`, `dashboard-smoke.js`), redirect `analytics/dashboard.html`.

## 8X4 Update the docs
README › Analytics and consent and › Owner dashboard describe the single place.
