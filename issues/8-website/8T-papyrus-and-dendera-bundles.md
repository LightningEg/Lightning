## Report

The cart offers the cheaper set (8N), and Nile, Dusk and Cotton have one. Papyrus and Dendera have none: the catalogue has no matching banner, frame or name for either, so there is nothing to bundle. See the store and community audit: `reports/2026-10-27-store-and-community/report.md` (B1).

## Fix

- Design a banner, a frame and a name colour for each theme (guideline `themes.md` and website Part B for what a look may and may not change), review them with the owner, then add them to the catalogue at their tier prices.
- Add a set per theme (`set_parts` rows) so the cart's set suggestion and the Sets tab cover all four app themes. Sets follow their parts at 80%.
- Keep the rule that a look changes no number or rank.
