## Report

[Audit](../../reports/2026-10-27-store-and-community/report.md) S1. Zero stories submitted.

## Fix

- One form: paste the link to your post, one line on how you use Lightning, tick consent. The page gives the code and the link to put in the post; no separate draft step.
- Owner review in one row: open the post, *Approve · 100 coins + 50 points* / *Ask for a change* / *Decline*. Keep the three-a-month cap and the code check.
- Approved stories show on Guides and each topic page (*How people use Lightning*), on the author's profile and on the leaderboard as points.
- Reward ladder in the console (owner sets): post 100 coins; a post that reaches the blog an extra 100.
