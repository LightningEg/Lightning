# The plan

**What is open, who can take it and what blocks what is on GitHub, not in this file.** Run `python tools/board.py`, or open
[the issues](https://github.com/LightningEg/Lightning/issues): [launch](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Alaunch) ·
[after launch](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Aafter-launch) · [someday](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Asomeday).
Rules for taking one: [skills/dispatch](../skills/dispatch/SKILL.md).

This folder keeps what an issue is too small for: each item's **design file** (linked from its issue) and the
**reports** that started it ([REPORTS.md](REPORTS.md)), in one folder per big picture ([README.md](README.md)).
`python tools/issues.py` prints the design files by milestone and checks they are well formed. New findings are one
line in [INBOX.md](INBOX.md).
