# Egyptian bank logo files

Individual, real logos under assets (not a ZIP). Not generated by AI.

* \`icons/<id>.png\` — 256x256 PNG icon for account rows.
* \`wordmarks/<id>.png\` — 512x192 PNG with original proportions.
* \`originals/<id>.webp\` or \`.png\` — fetched source file.
* \`manifest.json\` — lookup of stable IDs and asset paths, including provenance.
* \`download-report.json\` — import status.

Examples: assets/bank-logos/icons/cib.png, assets/bank-logos/icons/nbe.png.

Original sources: https://banksegypt.com/banks (36 logos, third-party directory) and https://www.onebank.eg (onebank logo). Please check current branding and trademark permissions before a public release; no affiliation or endorsement is implied.
