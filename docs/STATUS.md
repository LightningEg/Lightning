# Where Lightning stands

What is open changes every hour, so it is not written here. It lives on GitHub:

- **[Launch](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Alaunch)**: what must be finished before launch.
- **[The launch checklist](https://github.com/LightningEg/Lightning/issues/579)**: every step that needs a real device, a real account or a person.
- **[After launch](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Aafter-launch)** and
  **[someday](https://github.com/LightningEg/Lightning/issues?q=is%3Aopen+label%3Awhen%3Asomeday)**.

`python tools/board.py` prints the same as one tally: shipped, running, ready, needs a person, blocked. What has
shipped is in [RELEASES.md](../RELEASES.md). The nine pillars are explained in [the map](README.md).
