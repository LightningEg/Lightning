# Capture

*Getting money in with the fewest taps.*

Add an entry, import a bank CSV and settle every row yourself, read bank SMS on Android, let rules file the usual things, find anything with one search. A ledger that is not filled in answers nothing, so this is where convenience is won or lost.

**Deeper:** Architecture › CSV import and export contract · Search and identity contract. How the pillars fit together: [the map](../README.md).
