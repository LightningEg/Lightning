# Capture

*Getting money in with the fewest taps.*

Add an entry, import a bank CSV and settle every row yourself, read bank SMS on Android, let rules file the usual things, find anything with one search. A ledger that is not filled in answers nothing, so this is where convenience is won or lost.

On Android, open **From SMS → New SMS payments** to choose which payments to review. The default automatically saves payments Lightning can classify. You can also log recognized purchases under **Unaccounted** when there is no category yet. **Saved for you** lets you undo an automatic entry. From the phone inbox you can link a message to an existing entry, or choose a payee and category for a purchase. Choose **Remember for this account and merchant label** to reuse that choice for matching messages.
